## Giới thiệu

Đây là repository cá nhân được sử dụng để tổng hợp các bài tập trong quá trình học khóa **Fullstack K2**.

Mục tiêu của repo là ghi lại quá trình rèn luyện kỹ năng lập trình web từ nền tảng đến nâng cao, bao gồm **HTML**, **CSS**, **JavaScript** và các kiến thức liên quan đến phát triển ứng dụng web.

Repo này không chỉ là nơi nộp bài tập, mà còn là nơi tôi luyện tư duy giải quyết vấn đề, viết code rõ ràng hơn và từng bước xây dựng nền tảng để trở thành một lập trình viên Fullstack.

## Nội dung học tập

Repository bao gồm các bài tập theo từng buổi học:

- HTML cơ bản
- CSS cơ bản và nâng cao
- Responsive layout
- JavaScript nền tảng
- DOM manipulation
- Array methods
- Function, callback, scope
- Rest parameter và spread operator
- Prototype trong JavaScript
- Xử lý dữ liệu với Array và Object
- Xử lý dữ liệu dạng nested array/object
- Đệ quy
- Các bài tập thực hành tư duy logic
- Mini exercises theo từng chủ đề
